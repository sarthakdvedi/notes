## Access and Refresh Token -
- __Access Token__ - short term ( this is the regular jwt token, which is not stored into db )
- **Refresh Token** - long term ( also saved in db )

### The Refresh Token is a "Master Key"

The `refreshToken` is generated by your server to keep the user logged in for days or weeks.

- It belongs strictly in a **secure, HTTP-only cookie**, or safely tucked away in your database.
- If you accidently return it in the JSON response body (`res.json()`), it gets exposed to the browser's JavaScript environment.
- This opens the door for **XSS (Cross-Site Scripting) attacks**, where a hacker's script can read the token from the response and steal the user's entire session.
