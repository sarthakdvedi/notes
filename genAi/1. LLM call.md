## Demystifying the LLM Call (Internals)

### Input Structure (The Request Payload)

Making an LLM API call requires passing key parameters to the completion endpoint:

- **Model Identifier (`model`):** Specifies which model processes the request (e.g., `gpt-4o`, `gpt-3.5-turbo`).
    
- **Messages List (`messages`):** A sequence of dictionary objects defining conversation context using specific roles:
    
    - **Role (`role`):** Identifies who is speaking. ( differentiate messages eg. among user and assistant )
        
        - `user`: Instructions, prompts, or questions provided by the end-user.
            
        - `system`: Sets the behavior, context, and guidelines for the AI assistant.
            
        - `assistant`: Prior responses from the LLM (used to maintain context history).
            
    - **Content (`content`):** The actual text message/string assigned to that specific role.
        

### Output Structure (The Response Payload)

The API call does **not** simply return a plain text answer. It returns a complex JSON/Object payload containing metadata and execution details:

1. **`choices` (List):**
    
    - Contains generated completions (usually 1 completion by default).
        
    - Key attributes inside `choices[0]`:
        
        - `message.content`: The actual generated response text from the model.
            
        - `finish_reason`: Indicates why generation stopped (e.g., `'stop'`, `'length'`).
            
2. **`usage` (Object):**
    
    - Tracks token consumption for billing and context limit tracking.
        
    - Attributes:
        
        - `prompt_tokens`: Tokens used by your input request.
            
        - `completion_tokens`: Tokens generated in the output response.
            
        - `total_tokens`: Sum of prompt + completion tokens.


```python
import os

from dotenv import load_dotenv

from groq import Groq

  

# 1. Load API key from .env

load_dotenv()
my_api_key = os.getenv("GROQ_API_KEY")

if not my_api_key:

    raise ValueError("API key missing! Check your .env file.")

  

# 2. Initialize Groq client

client = Groq(api_key=my_api_key)

  

# 3. Model & prompt definition

model = "openai/gpt-oss-120b"

role = "user"

prompt = "Who is Padho with Pratyush?"

  

# 4. Single message dictionary

message = {

    "role": role,

    "content": prompt,

}

  

# 5. List of messages expected by Groq API

messages = [message]

  

# 6. API call using the exact variables

response = client.chat.completions.create(

    model=model,

    messages=messages,

)

  

# 7. Print raw response payload

print("--- RAW API RESPONSE ---")

print(response)

print("\n" + "="*50 + "\n")

  

# 8. Extract response text using choices array

answer = response.choices[0].message.content

print("--- EXTRACTED ANSWER ---")

print(answer)
```
