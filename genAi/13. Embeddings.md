# Embeddings & Vector Retrieval

## 1. The Core Problem with Keyword Search

- In basic RAG (Retrieval-Augmented Generation), standard keyword search is naive/dumb.
    
      
    
- **Limitations of Keyword Search:**
    
      
    - Fails on spelling mistakes.
        
          
        
    - Fails when words differ even if the meaning/intent is the same (e.g., "traffic jam" vs. "heavy traffic").
        
          
        
    - Strict string matching leads to high failure rates in retrieval systems.
        
          
        

## 2. Human Understanding vs. Machine Search

- **Human Cognition:** Humans do not process conversations using exact keyword matching; they interpret semantic meaning and context.
    
      
    
- **Machine Limitation:** Computers naturally understand numbers, binary, and math, but they do not inherently understand human vocabulary, context, or semantic relationships.
    
      
    

## 3. What is an Embedding?

- **Definition:** An embedding is the process of converting unstructured data (text, images, audio) into a numerical array or vector based on underlying features.
    
      
    
- **How It Works (Conceptual Example):**
    
      
    - Consider converting food items into a 2D vector using two features: `[Sweetness, Crunchiness]` (scored from 0 to 10).
        
          
        - `Apple` $\rightarrow$ `[8, 7]`
            
              
            
        - `Cake` $\rightarrow$ `[10, 2]`
            
              
            
        - `Kurkure` $\rightarrow$ `[1, 9]`
            
              
            
    - By comparing the differences between vector numerical scores, a system can quantify semantic similarity. For instance, `Apple` is closer in feature space to `Cake` than `Kurkure` is to `Cake`.
        
          
        

## 4. Vector Dimensions & Real-World Embeddings

- A 2-feature (2D) vector is too limited to capture complex real-world data.
    
      
    
- **Dimensions (Vector Length):** Higher-dimensional vectors capture a broader range of features (e.g., size, age, category, context).
    
      
    - Common embedding sizes: 384, 768, 1536+ dimensions.
        
          
        
    - **Trade-off:** Larger vector dimensions capture higher feature accuracy and semantic richness, but require more computational power.
        
          
        

## 5. Cosine Similarity & Mathematics

- **Definition:** Cosine Similarity measures the angle between two multi-dimensional vectors in a vector space to determine how similar two pieces of text are.
    
      
    
- **Score Interpretation:**
    
      
    - **Close to 1.0:** Highly similar / Same meaning.
        
          
        
    - **Around 0.5:** Moderately similar / Related domain or context.
        
          
        
    - **Close to 0 or Negative:** Unrelated or opposite meanings.
        
          
        
- Math details (like exact dot products or formulas) are handled under the hood by machine learning models; understanding the directional similarity concept is what matters for application engineering.
    
      
    

## 6. How Vector-Based Retrieval Works in RAG

1. **Document Embedding:** Convert all document chunks in the Knowledge Base into vectors.
    
      
    
2. **Query Embedding:** Convert the incoming user query into a vector using the same embedding model.
    
      
    
3. **Similarity Search:** Calculate the Cosine Similarity score between the query vector and all knowledge base vectors.
    
      
    
4. **Top-K Selection:** Select the top $N$ text chunks with the highest similarity scores and pass them to the LLM to generate the final answer.
    
      
    

## 7. Practical Implementation Notes

- **Dedicated Embedding Models:** Standard text-generation LLMs are not typically used for creating embeddings. Dedicated embedding models (such as `sentence-transformers` like `all-MiniLM-L6-v2`) are used instead.
    
      
    
- **Key Python Libraries:**
    
      
    - `sentence-transformers`: For generating sentence vector representations.
        
          
        
    - `numpy`: For efficient array operations and calculating similarity scores.
